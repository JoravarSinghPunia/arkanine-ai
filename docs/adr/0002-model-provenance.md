# Ship only open-weight models from US and European labs

Defence security reviewers are likely to reject Chinese-origin weights (e.g. Qwen, DeepSeek) regardless of benchmark scores. The offline bundle includes only open-weight models from US and European labs (e.g. Llama, Mistral, Gemma, gpt-oss), and provenance is a stated product guarantee. This gives up some benchmark performance for easier security review.
