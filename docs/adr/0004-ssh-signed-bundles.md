# Sign Offline bundles with SSH signatures over a checksum list

A security reviewer must be able to check a bundle without trusting Arkanine's tooling, on a machine with no network and nothing extra installed. Each bundle carries a `SHA256SUMS` file that lists every other file, and an Ed25519 signature over it made with `ssh-keygen -Y sign`. Both can be checked with tools that ship with macOS and every Linux distribution (`sha256sum` or `shasum`, and OpenSSH 8.2 or later). minisign and GPG were rejected because they are not installed by default, and X.509 code signing because it needs a certificate authority. A bundle is trusted only against a public key the operator already holds: one received separately for the first install, then the one kept by the installation for every later upgrade. The key inside a bundle never vouches for that bundle. This costs us key rotation and revocation, which will need a new decision before customer-held keys arrive.
